# Документация по библиотеке

 подключение к проекту:
 -

 > Перед импортом библиотеки необходимо положить в папку с кодом файлы Robot.h, Robot.cpp и constants.h

 > Либо не распаковывая zip архив через: скетч -> подключить библиотеку -> добавить .zip библиотеку
```cpp
#include "Robot.h"
Robot robot; //экземпляр класса Robot, можно назвать как удобно

```
в setup необходимо добавить:
-

```cpp
void setup() {
	robot.setupRobot();

	// остальной код setup()
}
```

описание команд:
-

* void setupRobot(); - автоматическая подготовка робота к работе
 
* void stop(); - полная остановка робота
 
* void setRDirection( bool ); - установка направления вращения правого мотора (по умолчанию направление настроено), значение true/false
* void setLDirection( bool ); - установка направления вращения левого мотора (по умолчанию направление настроено), значение true/false
> true - вперед, false - назад

* void setRSpeed( int ); - скорость вращения правого мотора 0-255
* void setLSpeed( int ); - скорость вращения левого мотора 0-255

* void rotateServo( int ); - повернуть сервопривод робота, угол 0-180
> угол 0 — это крайнее левое положение, 90 — центр, 180 — крайнее правое.

<u> примечание: </u>
* Методы setDirection, setSpeed, rotateServo имеют внутри защиту от ввода некорректных значений
