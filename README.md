 >Ардуино IDE сама подтянет примеры и будет подсвечивать методы класса Robot.
```cpp
#include "Robot.h"
Robot robot; //экземпляр класса Robot, можно назвать как удобно

```
в setup необходимо добавить:
-

```cpp
void setup() {
	robot.setupRobot();

	// остальной код setup()
}
```

описание команд:
-

* void setupRobot(); - автоматическая подготовка робота к работе
 
* void stop(); - полная остановка робота
 
* void setRDirection( Direction ); - установка направления вращения правого мотора (по умолчанию направление настроено), значение FORWARD/BACKWARD
* void setLDirection( Direction ); - установка направления вращения левого мотора (по умолчанию направление настроено), значение FORWARD/BACKWARD
```
void loop(){
	robot.setLDirection(FORWARD); //true / false не так очевидно, в последних версиях направление задается ключевыми словами
	robot.setRDirection(BACKWARD);
```

* void setRSpeed( int ); - скорость вращения правого мотора 0-255
* void setLSpeed( int ); - скорость вращения левого мотора 0-255

* void rotateServo( int ); - повернуть сервопривод робота, угол 0-180
> угол 0 — это крайнее левое положение, 90 — центр, 180 — крайнее правое.

* bool button1(); - получить состояние первой кнопки
* bool button2(); - получить состояние второй кнопки

* void ledRed(int); - яркость красного светодиода 0-255
* void ledGreen(int); - яркость зеленого светодиода 0-255

* int photoResistor(); - вернет напряжение на А0 0-1023
* 
> так же есть перегрузки:
* int photoResistor(int from,int to); - вернет напряжение на А0 через map 0-1023 переведет в вид from to
* int photoResistor(int from1, int to1, int from2, int to2); - вернет напряжение на А0 через map from1 to1 переведет в вид from2 to2


* bool leftLine(); - вернет состояние левого датчика линии
* bool rightLine(); - вернет состояние правого датчика линии

* long getFrontDistance(); - вернет расстояние до препятствия переднего дальномера или -1 если стена слишком далеко
* long getLeftDistance(); - вернет расстояние до препятствия левого дальномера или -1 если стена слишком далеко

<u> примечание: </u>

1 Методы setDirection, setSpeed, rotateServo имеют внутри защиту от ввода некорректных значений

2 getDistance() приостанавливает работу робота до 30мс.

3 использование delay() в loop() так же нежелательно, так как робот на это время не сможет опрашивать датчики. 
лучше использовать millis();
